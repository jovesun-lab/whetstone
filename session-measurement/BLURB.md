## Releases-tab summary (one paragraph)

> **Session Measurement v0.1.0.** You change an agent — a new model, a reworked frame, a new skill — and you want to know if it actually helped. A single session can't tell you; the signal is in the trend. This skill turns each session into six honest counts (redefinitions absorbed · clarifying gates raised · errors self-caught · misses the human caught · critical bugs, agent- vs human-caught) plus version and a main-goal-landed mark, kept in a plain-markdown trend table you read across versions. Markdown is the canonical output — zero dependencies, any agent; an optional script renders charts. The real value is the counting disciplines: prefer full reads, never fabricate a number you can't retrieve, ground against an authoritative record, and treat the human-caught rows as the honesty anchor when an agent scores itself. MIT.
